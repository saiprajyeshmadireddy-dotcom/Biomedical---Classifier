# Dataset files

Large CSV datasets are intentionally not included in this GitHub-ready archive because GitHub rejects individual files larger than 100 MB.

Excluded from this archive:
- `mitbih_train.csv` (~392 MB)
- `mitbih_test.csv` (~98 MiB; its byte size can exceed GitHub's 100 MB per-file limit)

Download the datasets separately from their original source and place them in this folder before running the project. Do not commit the large CSVs to the normal Git repository; use Git LFS or an external dataset link if the challenge requires them to be versioned.
